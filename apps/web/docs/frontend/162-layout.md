# 162 - Profile Layout

The Layout uses a classic social-profile structure enhanced for travel:
1. **Hero**: Edge-to-edge cover photo, overlapping avatar, verification badges, and top-level actions (Edit, Search, Share).
2. **Tabs**: `ProfileTabs` provides sticky navigation across major content zones.
3. **Stats Bar**: A 4-column metric bar sits above the main content to highlight the user's travel achievements.
4. **Grid**: The Overview tab splits into a 2/3 and 1/3 layout (Main Content vs Activity Timeline).
