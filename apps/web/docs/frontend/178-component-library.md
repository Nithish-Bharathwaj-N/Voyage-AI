# 178 - Component Library

### `SettingsSidebar`
A responsive navigation component that snaps from a vertical list (`flex-col`) on Desktop to a horizontal scrolling list (`flex-row overflow-x-auto`) on Mobile.

### Cards
Every settings section (e.g. `AccountCard`, `PrivacyCard`) is wrapped in a standardized `.bg-card.border.rounded-2xl.p-6` container, ensuring uniform spacing and aesthetics.
