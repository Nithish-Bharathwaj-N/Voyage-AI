# 128 - Component Library

### WizardProvider
Root provider wrapper for the wizard route. Requires `totalSteps`.

### WizardLayout
Accepts `steps` array and handles responsive layout (sidebar on desktop, top progress bar on mobile).

### WizardSidebar
Desktop navigation with step validation indicators.

### WizardProgress
Mobile header displaying standard "Step X of Y" and a progress bar.

### WizardFooter
Sticky action bar providing Back/Next/Submit actions.
