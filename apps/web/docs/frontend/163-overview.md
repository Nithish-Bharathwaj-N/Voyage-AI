# 163 - Overview Tab

The Overview tab is the default landing state. It acts as an executive summary of the user.
- **OverviewCard**: Displays the user bio.
- **TravelPreferencesCard**: Surfaces the user's saved travel styles.
- **RecentTripsCard & CollectionsPreviewCard**: Offer deep links to the respective domain hubs.
- **ActivityTimeline**: A vertical timeline feed on the right side detailing recent user actions.
