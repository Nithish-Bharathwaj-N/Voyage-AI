# 143 - Overview Block

The Overview block provides the critical 30-second summary of a destination:
- `OverviewCard`: Displays the prose description, language, timezone, currency, and visa requirements.
- `WeatherCard`, `BudgetCard`, `SafetyCard`: Three quick-read widgets placed in a 3-column subgrid. 

This section is optimized for visual hierarchy—the most important, actionable information is surfaced first.
