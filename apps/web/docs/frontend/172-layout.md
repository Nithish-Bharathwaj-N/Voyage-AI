# 172 - Settings Layout

The Layout uses a classic master-detail interface:
1. **Sidebar Navigation (`SettingsSidebar`)**: Vertical menu on Desktop that transforms into a horizontally scrollable chip menu on Mobile/Tablet.
2. **Content Area**: Dynamic area that renders the currently selected configuration card.
3. **Save Mechanism**: A "Save Changes" button sits at the top right for desktop. On mobile, it becomes a sticky action bar fixed to the bottom of the screen to ensure it's always reachable.
