# 45. Layout Guidelines

- **No generic padding**: The Planner components must handle their own internal padding.
- **Z-Index Strategy**: The Toolbar is `z-40`, Sticky Day Headers in the Canvas are `z-20`, and Map Controls are `z-10`.
- **Backgrounds**: The canvas uses `bg-muted/10` to contrast against the pure `bg-card` of the activity cards, creating depth.
