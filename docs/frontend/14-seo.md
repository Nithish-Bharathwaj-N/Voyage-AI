# 14. SEO Implementation

SEO is built directly into the Next.js `layout.tsx` via the Metadata API.

- **Title**: VoyageAI | Travel Intelligence Platform
- **Description**: Plan smarter. Travel confidently. Powered by intelligent planning.
- **OpenGraph**: Configured for Twitter Cards (`summary_large_image`) and Facebook shares.
- **Static Assets**: Basic `robots.txt` and `sitemap.ts` have been generated to ensure web crawlers can index the `(marketing)` group while ignoring the `(app)` group.
