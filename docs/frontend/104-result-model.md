# Result Model Cards (104)

Documentation for domain-specific visual card layouts inside the command palette list.

## Card Components
- `DestinationResult`: Displays high-resolution destination images, rating details, and pricing weights.
- `TripResult`: Showcases active user itinerary planners with duration days.
- `ActivityResult`: Highlights curated tourist sightseeing excursions.
- `HotelResult` & `RestaurantResult`: Focuses on locations, star ratings, and price levels.
- `FlightResult`: Maps active departure times, airline brands, and numbers.
- `CommandResult`: Showcases keyboard shortcut badges (e.g. `⏎`) for quick system interactions.
