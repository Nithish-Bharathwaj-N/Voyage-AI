# 13. Sections Configuration

The 10 core sections of the marketing site:

1. **Hero**: The highest-converting area. Uses a massive "fake UI" product preview to show, not tell.
2. **Trusted Tech**: Social proof via grayscale-to-color hover badges.
3. **Features**: Standard 3-column grid highlighting the 6 core pillars.
4. **Showcase**: Alternating left/right deep dives into the Planner and Copilot.
5. **How it Works**: A 4-step vertical (mobile) or horizontal (desktop) timeline.
6. **Why VoyageAI**: A brutal comparison table exposing the flaws of traditional tools.
7. **Testimonials**: 3-column card grid of social proof.
8. **Pricing**: 3-tier card layout scaling the `Pro` tier via `scale-105`.
9. **FAQ**: Framer Motion powered accordion.
10. **CTA**: Massive contrast block driving the final signup.
