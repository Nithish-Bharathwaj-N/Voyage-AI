# 04. Navigation System

Navigation components must support deep nesting and active-state routing.

## TopNavbar
A slim, blurred sticky header supporting breadcrumbs and the global Profile dropdown.

## Sidebar
A collapsible vertical navigation supporting grouping (e.g., "Your Trips", "Collections"). Built with `framer-motion` to smoothly interpolate between the expanded (250px) and collapsed (64px icon-only) states.
