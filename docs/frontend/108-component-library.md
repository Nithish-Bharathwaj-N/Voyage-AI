# Search Component Library (108)

Maps out reusable search components and result cards details.

## Components Registry
- `GlobalSearch`: Main palette container.
- `SearchInput`: Focusable query input panel.
- `SearchResults`: Track listings.
- `SearchFilters`: Horizontal tab selectors.
- `SearchHistory`: Stores past searches and pinned actions.
- `SearchStates`: Loading, empty, and error templates.
- `UnifiedResultCard`: Dynamic layout switcher matching domain tags.
