# 37. Motion

Framer Motion is used for micro-interactions to make the workspace feel "alive".
- **Quick Actions**: Utilize `whileHover={{ scale: 1.02 }}` and `whileTap={{ scale: 0.98 }}`.
- **Command Palette**: Appears with a slight backdrop blur and instant layout shift.
- **Images**: `group-hover:scale-105` is used on native CSS for performance on Trip Card cover images.
