# Component Library Specification (99)

Details reusable subcomponents and primitives created for the travel discovery engine.

## Primitives list
- `DestinationCard`: Core visualization card supporting `variant` parameter layout configurations.
- `SwipeableCarousel`: Horizontal scroll snapping track.
- `DiscoverySection`: Layout grouping wrapper for destination rows.
- `ExploreFilters`: Filters configuration widget.
- `EnhancedSearch`: Suggestion autocomplete query field.
- `QuickPreview`: Right slide-out detail inspector sheet.
