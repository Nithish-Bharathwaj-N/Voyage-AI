# 44. Responsive Workspace

- **Desktop (`lg`+)**: The 3-column layout is fully active (Sidebar - Canvas - Map/Context).
- **Tablet (`md`)**: The Sidebar remains, but the Right Panel (Map/Context) collapses behind a drawer or is pushed below the fold.
- **Mobile (`sm`)**: Both sidebars collapse into hamburger menus. The Canvas occupies 100% of the screen.
