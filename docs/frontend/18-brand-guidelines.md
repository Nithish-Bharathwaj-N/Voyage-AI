# 18. Brand Guidelines

VoyageAI is a premium Travel Intelligence Platform.

- **Logo**: The primary `Plane` icon rendered inside a rounded-md `bg-primary` block.
- **Colors**: Strictly monochrome (Zinc and White). Color is only used for semantic states (Destructive Red) or to draw attention to specific UI elements in the "Fake UI" product previews (e.g., weather icons).
- **Typography**: Inter (or system sans-serif) with tight tracking (`tracking-tight`) for headings to give a modern, editorial feel.
