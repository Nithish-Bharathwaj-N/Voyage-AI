# 11. Responsive Design

VoyageAI is a Desktop-first platform for heavy planning, but must be mobile-friendly for traveling.

## Breakpoints
- **Desktop (`lg` - 1024px+)**: Full `WorkspaceLayout` (Map + Left Sidebar + Right Timeline).
- **Tablet (`md` - 768px+)**: Left Sidebar collapses into a drawer. Map remains visible.
- **Mobile (`< 768px`)**: The map is hidden by default behind a tab. The user focuses strictly on the scrolling timeline and day plans (ideal for on-the-ground travel execution).
