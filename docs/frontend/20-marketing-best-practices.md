# 20. Marketing Best Practices

1. **No External Libraries**: Do not install heavy carousel libraries or scroll-jacking libraries. If we need a carousel, build it natively with Framer Motion.
2. **Accessible Headers**: The DOM must contain exactly one `<h1>` tag (The Hero Section). All subsequent sections must use `<h2>`.
3. **Contrast**: Text overlaid on background images (e.g., The Final CTA) MUST have a dark overlay (`bg-primary` with `mix-blend-overlay` image opacity) to ensure the text remains legible.
