# 10. Future Multi-Agent Roadmap

This Orchestrator is designed to scale into a multi-agent system.

## The Vision
Instead of one massive prompt, the Orchestrator will route tasks:
1. **The UX Agent**: Chats with the user, determines intent.
2. **The Research Agent**: Interfaces with the Knowledge Engine via MCP to find the best places.
3. **The Planner Agent**: Computes the optimal route and timeline.
4. **The Reviewer Agent**: Validates the final plan against user preferences.

This phase implements the foundation for this multi-agent Swarm architecture.
